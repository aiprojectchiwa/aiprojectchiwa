### 💫 About Me

Hellow~ I’m **Ai**, but most people know me as **Chiwa**
Originally, I started as an *AI enthusiast* - that’s actually why I picked the name “Ai".  
Over time, my nickname changed to Chiwa, but I kept my GitHub username for sentimental reasons - it holds all my earliest memories of learning to code.

My coding journey began with a simple curiosity:  
> *“How can someone change their voice using AI?”*  

That tiny question pulled me deep into the world of programming.  
At first, I just copied Python code and tweaked little things, not really knowing why.  
But later, I found my purpose - to **create things that feel alive.**

Now, I’ve been coding mainly in **JavaScript**, **TypeScript**, and **React**,  
and recently, I’ve started exploring **Go (Golang)** too!  
From writing messy vanilla JS and CSS to falling in love with the structure of TypeScript -  
I used to *hate* TS… but now I adore how clean and maintainable it makes my code

Right now, I’m focusing on **school**, doing **some freelance projects**,  
and preparing for **college soon!** (yaaay >.< 🎓)
